# itsabubakar.me

Portfolio of Muhammad Abubakar, lead blockchain engineer (exchange infrastructure & L1 forks). Next.js 16 (App Router), React 19,
Tailwind v4, Three.js via React Three Fiber, GSAP + ScrollTrigger, Lenis.

The art direction is called **Live Figure**. A stylised 3D developer, sculpted in code, stands in a ring of
linked blocks that appends a new block every few seconds. The head follows your pointer. Around it the site
reads like a technical journal, and each project is shown as a working simulation of its architecture.
Design and engineering rules live in `.claude/skills/`.

```bash
npm run dev      # http://localhost:3000
npm run build    # production build (fetches Google Fonts and generates the OG/Twitter images)
npm start
npm run avatar   # re-bake public/models/avatar.glb from scripts/avatar/
```

## Contact form (Formspree)

The form posts to `app/api/contact/route.ts`, which validates (`lib/contact.ts`, shared with the client) and
forwards the message to [Formspree](https://formspree.io) form `xnpjvnbv` (`site.formspreeId` in `data/site.ts`).
Formspree emails it to the address on the account that owns the form, with reply-to set to the sender.

There is nothing to configure in the environment. To change where mail lands, change it in Formspree; to use a
different form, change `formspreeId`.

The route stays in front of Formspree so the site keeps its own validation, honest error states and spam
protection: honeypot, 3 s minimum fill time, 5 sends / 10 min per IP (in-memory, per instance), link limit and a
same-origin check. With JavaScript disabled the form posts normally and redirects to `#contact-sent` /
`#contact-failed`.

## Case-study pages

SILPRE and SWAP21 each have their own page at `/work/<id>`, generated by `app/work/[slug]/page.tsx`
from `data/projects.ts` (a study opts in with `detail: true`, and `generateStaticParams` prerenders it).
The home-page card links to it with "Full case study"; `app/sitemap.ts` picks the routes up automatically.

Both pages carry an **attribution block** (`components/sections/work/Delivered.tsx`) naming the company
the work was delivered at, the role, the period, and what part is Muhammad's — these are employer
products, not personal projects, and the page says so. It is driven by the `delivery` field on a project
and also appears in compact form on the home-page cards.

Because section anchors live on the home page, `Navigation` renders `/#about` style links on sub-pages
(`usePathname`), and `SmoothScroll` only intercepts hash links whose pathname matches the current page.

## Screenshots

Case-study screenshots live in `public/shots/` as ~1600px WebP (≈40–65 KB each), rendered through `next/image`
with a lightbox (`components/sections/work/Shots.tsx`). Alt text describes what each interface shows and lives
beside the image in `data/projects.ts`.

The full-resolution originals are in `assets/screenshots/` — **outside `public/`, so they are not served**. One of
them (the SWAP21 P2P page) shows another user's email address; keep it out of `public/`. To add a shot, drop the
original in `assets/screenshots/`, resize it to ≤1600px WebP into `public/shots/`, and add an entry with honest
alt text to the project's `shots` array.

`public/resume.pdf` is generated from `Muhammad_Abubakar_Lead_Blockchain_Engineer.docx`; to update it, replace
the PDF (Word → File → Save As → PDF). Book-a-call and résumé buttons only render when the link / file exist.

## The avatar

`npm run avatar` rebuilds the model from `scripts/avatar/character.mjs` (signed-distance sculpt) and
`build-avatar.mjs` (hard-surface parts, materials, compression). To use a different model, replace
`public/models/avatar.glb`. Head tracking, blinking and breathing look for nodes named `Head`, `EyeL`/`EyeR`
and `Body`; Ready Player Me and Mixamo names also work. If you change the avatar or the lighting,
regenerate `public/images/avatar-poster.webp` too. It's the still shown when WebGL is unavailable.

## 3D quality tiers

Before mounting, `lib/three/quality.ts` picks `high`, `medium` or `low`. It picks `off` when WebGL2 is
missing, Save-Data is on, or the user prefers reduced data, and then the poster image is shown. Force a tier with
`?quality=high|medium|low|off`. With `prefers-reduced-motion` the scene renders as a single still frame, the
loader is a short fade and scroll effects are disabled.
